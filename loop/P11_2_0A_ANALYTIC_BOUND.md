## 2. 数学推导（原始归一化 LIF）

更新式（每步）：

```
v_{t+1} = decay * v_t + gain * (W @ spikes_t) + tonic + noise_t
decay   = exp(-dt / tau) = exp(-0.020 / 0.100) = 0.8187307530779818
tonic   = 0.14
gain    = 3.0            （只乘突触输入）
noise_t ∈ {0, 0.22}      P(0.22) = 1.2 * 0.020 = 0.024
threshold = 1.0; reset = 0
```

### 2.1 tonic 单独

固定点：

```
v* = tonic / (1 - decay)
   = 0.14 / 0.1812692469220182
   = 0.772331779...
```

**0.772331779 < 1 → tonic 单独永远不能发放。** 严格。

### 2.2 tonic + 均值噪声

均值噪声 = `0.024 * 0.22 = 0.00528`。固定点：

```
v* = (0.14 + 0.00528) / (1 - decay)
   = 0.14528 / 0.1812692469220182
   = 0.801459721...
```

**0.801459721 < 1 → 期望意义下不能维持每步发放。** 严格（均值是上界意义下的必要固定点；实际稀疏性需概率计算，但“每步连续”已被排除）。

### 2.3 无突触输入、每步都有最大噪声时的电压上界

从 reset（v=0）开始，假设每一步都发生噪声事件（这是**最大可能**输入；实际 p=0.024）：

| 步 | v 上界 | 达到阈值 1？ |
|---|---|---|
| 1 | 0.360000000 | 否 |
| 2 | 0.654743071 | 否 |
| 3 | 0.896058288 | 否 |
| 4 | 1.093630477 | **是** |

闭式：

```
v_k = (tonic + noise_amp) * (1 - decay^k) / (1 - decay)
v_1 = 0.36
v_2 = 0.654743071
v_3 = 0.896058288
v_4 = 1.093630477
```

**结论（严格）**：

- 无突触输入时，复位后**最早第 4 步**才能再次发放；
- 因此任意长度内发放次数 ≤ `ceil(T/4)`，长期发放占比 **≤ 0.25**；
- **无突触输入的单神经元不可能连续每步发放**。

**不能**由此声称：

- 递归输入是唯一原因；
- 稀疏（≤25%）tonic+noise 发放被排除；
- 噪声不是某些发放事件的触发因素。

### 2.4 瞬时突触输入门槛（reset 后）

在 reset（v=0）后，当前步要发放：

```
gain * I_raw + tonic + noise >= 1
```

- **无噪声**：`I_raw >= (1 - 0.14) / 3 = 0.2866667`（post-gain **0.86**）。
- **有最大噪声 0.22**：`I_raw >= (1 - 0.14 - 0.22) / 3 = 0.2133333`（post-gain **0.64**）。

**残留电压警告**：若前一步**未发放**，`v_t > 0`，下一步门槛为

```
gain * I_raw >= 1 - decay*v_t - tonic - noise
```

**不得**套用 reset=0 的 0.86 / 0.64 门槛。本报告只在“前一步确实发放并复位”的 KC 上使用 reset 门槛。

- 主窗口 t∈[100,300)。

### 3.5 解释（严格）

- **容量**：99.9262% 的连续发放事件中，KC→KC 净输入 ≥0.86；在**没有其他负输入**的假设下，KC→KC + tonic 已有跨阈值能力。匹配 320 KC **全部 ≥1.303277**。
- **不是因果**：正反馈容量不等于证明 KC→KC 是因果根因；未保存的 APL/其他非 KC 活动可能显著改变净输入。
- **不是完整电流**：本轮只重建 KC→KC；总突触电流 = KC→KC + 非 KC（未保存），**未知**。
- **不是唯一原因**：数学只排除“无突触输入时 tonic+noise 连续每步发放”；未排除噪声触发、APL 平衡、步长上限、其他非 KC 输入。
