# P5-1 报告：真实视觉机制的动态迫近（looming）刺激验证 → **NO-GO**

**基线** `91f9330`。P1–P4 结果冻结。不训练、不引入 ToF 转向/地图/目标/Dijkstra；不改正式权重/readout/BASE/tags；
不运行虚拟/实体车；不更换神经群搜成功率。

## 第一步：机制与数据核对（**拓扑可用，故非立即 NO-GO**）
- **文献**：T4(ON)/T5(OFF) 为方向选择性运动检测器；**LC4 迫近敏感 VPN**；**LPLC2 为 looming 关键 VPN，主要驱动来自 T4/T5**。
- **本连接组实测**（`brain.npz/weights.npz`）：
  - `LC4` 126 个、`LPLC2` 185 个、`LPLC1` 134 个；T4/T5 以 `T4a-d/T5a-d` 存在。
  - **LPLC2 ← T4a-d/T5a-d：平均入权 0.32、33,409 条边**（looming 通路成立）；LC4 ← T4/T5：0.020、3,978 边（较弱）。
- **感受野/拓扑核对**（不凭名称）：2 跳 `photo→ol→VPN` 的**有效感受野中心方位**——LC4：L 中位 **−0.51**（n=71）/ R **+0.51**（n=55）；
  LPLC2：L **−0.52**（94）/ R **+0.52**（91）；**侧别一致性 = 1.00**。→ **视网膜拓扑信息足以建立可信的左右输入**。

## 第二步：唯一输入模型（冻结）
**视网膜方位带（6006 光感受器，az∈[−1,1]）上的高斯带时空驱动**，经 `eye_drive` 加到**光感受器**；
**不**向 LC4/LPLC2/DN 注入任何"正确左转/右转"答案。
- 扩张(loom)：中心 c0∈{−0.5, +0.5}，σ(t) 0.10→0.60 线性扩张；收缩(contract)：σ 0.60→0.10；亮度(luminance)：方位均匀；无刺激(none)：对照。
- **生物证据** vs **人为建模**：T4/T5/LC4/LPLC2 身份、侧别、连接、方位映射 = **连接组数据**；高斯带刺激、σ 斜率、`eye_gain` 注入 = **人为建模**。

## 第三步：匹配对照
条件 = `none / left_loom / right_loom / left_contract / luminance`；**各条件总线能量相等**（预算匹配，见 `test_p5_looming` 断言）。

## 第四步：运行前冻结

**一律用同 seed「刺激−对照」同步窗差值**，不用 PRE→STIM 自然升高。

## 结论：**NO-GO**
真实连接组具备 **T4/T5→LPLC2 looming 通路 + 可用的侧化感受野拓扑**，刺激也确实驱动了光感受器与 T4/T5
（扩张为正、收缩为负）；但在**当前 LIF 动力学**下 **LC4/LPLC2 及下行靶无可靠、左右特异的神经响应**。
→ **NO-GO**：不进入后续运动功能研究、不做成功率搜索、不猜参数。若继续，需先解决"视觉级→VPN"的功能传递
