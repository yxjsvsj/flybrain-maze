# P3-1 报告：真实 MaleCNS 视觉感觉→下行运动通路可行性门控 → **NO-GO**

**基线** `be27553`。本轮只做这一项新研究。未改 MaleCNS 权重/神经参数、未改 P1/正式 readout/BASE/tags；
未接 P2Control、未运行虚拟或实体车、未训练、未加入地图/目标/老师；未继续调 L50/R50/NS/POP/EPG/PEN。
依据**官方 bodyId/类型/连接**（`brain.npz`+`weights.npz`），**不**按随机 seed 导航成功率筛神经元。
严格区分 **(A) 解剖连接** / **(B) 人工 LIF 活动** / **(C) 人工电机映射**。

## 1. 解剖证据（A）：**存在、强、可追溯**（`p31_visual_motor.json`）
- `visual_projection` 9,201 个、`descending_neuron` 1,314 个；**直接 VPN→DN 边 25,146 条**（总权 46.46）。
- 主要直达对（DN ← VPN，权）：`DNp04 ← LC4 1.10`、`DNg82 ← LPLC4 0.61`、`DNp02 ← LC4 0.52`、
  `DNp01 ← LC4 0.34`、`DNp03 ← LPLC1 0.39`、`DNp17 ← VST2 0.92` 等。
- **左右同源/方向可追溯**：关键视觉 VPN 到**同侧** DN 的权重占比
  **LC4 = 1.000、LPLC4 = 0.995、LPLC2 = 0.998、VST2 = 0.998、VSm = 0.978**
  （例外 `OCG01d` 对侧 0.998）。→ 左眼→左 VPN→**左** DN、右眼→右，具备方向特异的解剖基质。
- 间接 2 跳路径存在（`p31_indirect.json`：经 CB1638/AVLP094/cL01/CB3905… 等中间神经元，权重较小）。
- 全部按 **bodyId/类型/侧别** 记录，连接方向 = `W[post,pre]`（与 `brain.py::_propagate` 一致）。

## 2. 冻结的离线左右响应检测（B）：**无差异**
解剖清楚且可事前固定检测方案，故执行**一次**短时离线实验（`p31_response.json`）。
冻结：下行为 `STA_VPN=(LC4,LPLC4,LPLC2)` 的**直接** DN 靶集合（76 型，35 L/41 R）；刺激=左眼/右眼
光感受器恒定驱动 `A=0.5`（方位 <−0.3 / >0.3）；背景=无驱动；seed `[11,12,13,14,15]`；
窗 0.5s 预热 + 1.0s 刺激；门槛 `STABLE_MIN=4/5`（ipsi>contra 且 ipsi>背景）、`FALSE_MAX=1.0`。
- 结果：各条件 DN 发放几乎不变（base≈0.78/1.18、左眼≈0.83/1.21、右眼≈0.81/1.21 L/R）；
  **ipsi>contra 0/5 seed**；背景≈1.16 > `FALSE_MAX`。→ **判 NO-GO**。

## 3. 关键诊断：视觉驱动**未**传到 VPN（说明是功能缺失，非"刺激不好看"）
单次诊断（非新候选）：左眼驱动使**光感受器**发放 33.2→**717.4/步（+684）**，但 **VPN 视觉投射神经元
98.1→97.3（−0.8）**、**DN 30.5→31.3（+0.8）** → 刺激**到不了 VPN**，故左/右差异无法进入下行通路。
即：解剖基质**存在**，但当前 MaleCNS v0.1.0 的 LIF（tonic/gain 标定 + 权重）**功能上不接通**
"光感受器→视觉投射→下行"这条链；直接驱动光感受器不足以驱动 VPN。

## 4. 结论：**NO-GO**
- 解剖：**GO 级基质**（可追溯、ipsi 主导的视觉→下行路径）。
- 功能（本模型、冻结协议）：**无左右差异、无到 VPN 的传递** → **当前证据不足以进入任何虚拟闭环阶段**。
- 按 P3-1 规则：**NO-GO** ⇒ **暂停本模型（MaleCNS v0.1.0 现状）的脑控导航研发**。
  需要在**不改本模型**的前提下先解决"感觉→视觉投射"的功能接通（属另一课题），而非继续读出调参。
