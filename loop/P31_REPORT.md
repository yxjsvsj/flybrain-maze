## 1. 修正①：直接靶集合改用**原始 bodyId**（不再按 `dn_type` 合并）
- **修复前**（按类型）：**76** 个键；**修复后**（按 bodyId）：**138** 个细胞（**68 L / 70 R**）。

## 2. 修正②：二跳路径**方向**（严格 `W[post,pre]`；含正负权）
- 旧实现误用 `W.getrow(x)`（=x 的**入**权）当"x→下行"，方向错误；**旧 `p31_indirect.json` 已作废重算**。
- 修正：`in_w = Σ_v W[x, v]`（视觉→x），`out_w = Σ_d W[d, x]`（x→下行，取 `W[dn_sel, :]` 的**列** x）。
- 出权**可正可负**（抑制为负），同时给**带符号和**与**绝对值和**（`p31_indirect.json`，如 `AN_multi_11 out_signed=−0.270`、
  `PLP029 −0.246`、`AN_multi_28 +0.358`；`n_dn` = 该中间神经元直接连到的下行细胞数）。**正负相消**不再被忽略。

## 3. 修正③④⑤：连续同试次、同步多层计数（`p31_raw.npz` 逐步原始计数）

## 4. 关于 `FALSE_MAX` 的解释限制（**不**改门槛）
`FALSE_MAX` 原意是把"背景**误触发**"当失败证据，但实测的"背景"是**基线发放率**（DN 组 0.5–0.8/步）——**基线发放本身不是误触发**；
真正的误触发应是"无刺激时出现与刺激方向一致的伪响应"。本组数据**无**这种伪响应；故 `FALSE_MAX` 的"通过"**不构成 GO 支持**，
但也**不**应把基线发放当作系统缺陷。**门槛数值未改。**

## 5. 两层结论
- **(层1) 该固定视觉刺激协议是否通过 GO 门槛？** → **否（NO-GO）**：
  左右特异失效（ipsi>contra 仅 2/5）、`RESP_MIN` 未过、且 DN 反应为**非左右特异的整体升高**。
- **(层2) 数据支持哪种归因？** → **只能支持"此协议下未检出左右特异的传递"，不支持"通路功能断开"。**
  P3-1 原"视觉驱动到不了 VPN → 功能断开"的结论**被本次修正推翻/更正**：修正后测量显示驱动**确有**到达
  光感受器（+0.117/细胞）并引起**小幅 VPN 与 DN 整体升高**——通路**并非功能断开**，而是**缺乏左右特异（与刺激方向无关）**，
  在**不改本模型/不换刺激形式**的约束下无法形成可用的方向性视觉→下行信号。
