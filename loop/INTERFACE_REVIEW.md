## 一、感觉输入审计（五路 ToF → 编码 → 注入 → MaleCNS）

**路径**：`frame_from_pose`（raycast 5 路）→ `PhysicalToFEncoder.sense/update/inject`
→ 缓存 `_cache[L/R]=(loom,chase,threat,size,dmin)` → `inject` 把 `loom/chase/threat L/R`
按 `per_step=1-exp(-dt/τ)`（=**0.1813** @dt=0.02,τ=0.1）注入 `groups[...]` → `brain.step(inject=...)`。

- **[代码事实] 掩码由角度+`avoidance_fov_deg(120°)`/`front_cone_deg(40°)` 计算**：
  神经避障**左池=[FL,F]**，**右池=[F,FR]**，`front=[F]`（仅 front_safety）。**中心 F 同时进左右两池 = True**。
  **L/R(±70°) 不进任何神经池**（只走 `valid_mask` 供建图）。
- **[代码事实] NO_TARGET≠无输入**：`sense()` 把 NO_TARGET/IO_ERROR 记作 `dist=max_range`，
  `size=wall_size/max_range>0` → **仍有非零 chase 注入**（背景底噪）；TOO_NEAR 记 `MIN_DIST_M` 并触发 front_safety。
- **[代码事实] 分组未触发 fallback**（`LPLC2/LPLC2/LC4/LC4/LC10a/LC10a/DNa02×2/DNg100/MDN/DNp01` 均命中）：
  真实侧别 n = loom 94/91、threat 71/55、chase 135/140、**turn(DNa02) 1/1**、fwd 2、back 4、escape 2。
- **[代码事实] `sensory_input=False`**：把 **17937 个 sensory 神经元**的**入突触**（W 的对应行）置 0；
  **tonic/noise/recurrent 完全不变**（因此它只切"外感受上游"，不关网络自活动）。
- **[生物学依据]** 选用 LPLC2(looming)/LC4(快速 looming/逃逸)/LC10a(朝向目标/静态 proximity→DNa02)/
  DNa02(转向)/DNg100(前进)/MDN(后退)/DNp01(逃逸) 与果蝇文献一致；[人工假设] 只是**名到名**的映射，
  未验证"这些细胞在连接组里的实际权重是否承载避障"。
- **[人工假设] 已知弱点**：(i) F 双池会**稀释左右差**；(ii) NO_TARGET 底噪注入；
  (iii) **无任何本体感觉/运动反馈**（见四）。**缺口**：对"转弯何时结束"重要的**身体/运动状态**完全缺失。

## 二、神经动力学审计（实际安装 flybrain v0.1.0）

- **[代码事实]** `FlyBrain`：`dt=0.02, τ=0.1, gain=3.0, tonic=0.14, noise_hz=1.2, noise_amp=0.22,
  decay=e^{-dt/τ}=0.819, refractory=0`。每步：`v ← decay·v + gain·W·spike_prev + tonic + noise(伯努利1.2Hz×0.22) + eye + inject`，`v≥1 → spike`。
  即 **`inject=[]` 仍保留 tonic/noise/recurrent**。
- **[代码事实+实验] "无注入"非"无神经"**：P2d-19 的 `zero_injection` 下持续转向仍保持 97–124%；
  P2d-20 显示 **zero_from_start 就有 ~1.3–1.5 spikes/step、|D−b0|≈0.04–0.09、|turn|≈0.34–0.67**。
- **[实验] 背景 vs 障碍诱发**：P2d-21 背景 `|D−b0|≈0.063`、窗口 q99≈0.12；障碍诱发 `ΔD≈0.10–0.20`。
  **背景与诱发同量级**（约 1/2–2/3）→ 固定群体读出的信噪比本就低。
- **[生物学依据]/[人工假设] 不可等同处**：真实连接组的**接线**是实证的，但 `tonic/noise/gain/τ/无不应期`
  是**手工标定**（源码自述"hand-calibrated"），`DNg100` 还靠 `forward_drive_dv=0.5` **人工恒定注入**；
  模拟出的约 1Hz 静息放电不能当作果蝇真实静息态。
- **[结论] 模型问题 vs 读出问题**：背景自活动（tonic/noise 造成）**属模型**；把它用**固定 b0+gain=8**
  直接映射成大转向**属人工读出**。**不能**仅凭 P2d-19/20 断言"突触循环自维持"——本审查只能说：
  **在该模拟器参数下，背景活动足以产生与诱发同量级的读出。**

## 三、运动输出审计（DN → 读出 → turn → P2Control → world.car）

- **[代码事实] 真正由神经决定的只有 ω 分量**：
  `Decoder(dn)`: `turn=turn_gain·turn_sign·(r[turn_L]−r[turn_R])`；群体: `turn=clip(sign·gain·(D−b0))`。
- **[代码事实] 由人工恒定/手写层决定**：`v` 由 `readout_fwd_frac=0.75` 固定前进速度 + `front_safety`
  （stop 0.25/slow 1.0）决定；`turn_slowdown=0.5`、`smooth=0.35`、`clip(±1)`、`max_omega=2.6` 全为人工。
- **[生物学依据]/[人工假设] gap**：DNa02 **每侧仅 1 个神经元**→ 指令被量化；motor map（gain/sign/b0/τ）
  无物理或神经学验证；"D>0→负 ω"是**人工约定**，非天然运动解码。
- **[实验] 为何"首转对、却完不成转弯/回正"**：P2d-17 首转向 9/10 正确但累计转角 1000–3700°（打圈）；
  P2d-18/19/20 显示**撤除输入后仍持续**（背景/内部）；P2d-14 的短时保持反而更差。→
  **转向是"常开"的、缺回正**，且神经**看不到自己正在转**（见四），无法自行收敛。

## 四、随机迷宫目标的架构可达性

- **[代码事实] 神经可见**：仅 5 路 ToF（经编码）。**不可见**：车位置、朝向、是否在转、地图、终点。
  `brain.step(eye_drive=None, inject=...)` 参数里**没有位姿**——**车状态不回喂网络**（审计+测试证据）。
- **[代码事实] 无**：神经主导的运动记忆、方向保持、探索状态、目标选择（`trace` τ=0.2 只是**短时残留**）。
- **[判断] 当前局部避障**：能在单拐角"选边"（P2d-21 方向信号），但**无法支持有目的的迷宫探索**——
  **无方向保持**（转弯不会自己结束）、**无探索/回访状态**。
- **[判断] 有目的到达终点所缺**：① 神经系统自身可利用的**运动状态/朝向变化**（本体/efference copy）；
  ② 方向保持/整合（heading）；③ 探索/目标选择机制。**注意**：现有 Dijkstra/规划器的成功率**不是**果蝇脑成功率，
  不得混用。

## 五、唯一下一步建议（证据表 + 推荐）

| 现有能力 | 实验证据 | 主要不足 | 影响最终目标? | 优先级 |
|---|---|---|---|---|
| 局部避障**方向**信号 | P2d-21/21a：方向错 0/18，检出 80–100% | 无遮挡误报 4.6 事件/40s | 是 | 中 |
| 转弯的**结束/回正** | P2d-18/19/20：撤除输入后仍持续（背景/内部） | 无回正信号，转向"常开" | 是 | **高** |
| **运动状态/朝向**回喂 | P2d-23 审计：`brain.step` 无位姿，只有 ToF | 神经不知自己在转/朝哪 | 是 | **高** |
| 目标选择/探索/方向保持 | 无（仅局部避障） | 无 goal/heading 机制 | 是 | **高** |
| 感觉编码（F 双池；NO_TARGET 底噪） | P2d-13d：移除 F 于左右池**无改善** | 稀释/底噪（次要） | 是（次要） | 低 |
| 神经动力学模型适用性 | P2d-19/20：背景≈诱发同量级 | 参数手工标定 | 是 | 中 |
| 人工 motor map（gain/sign/b0） | P2d-13b/14/22：加保持/归一化均未改善 | 无物理/神经学验证 | 是 | 中 |

**推荐：D —— 补充"神经系统自身可利用的运动状态与导航信息"（回喂本体/efference-copy 式的自运动状态）。**

**证据链**：① 方向信号**存在**（P2d-21/21a：触发时方向 0 错）→ 需求不在"感觉没有左右"；
② 但转向**不会自行结束**（P2d-18/19/20：撤除输入仍持续）且**首转对、累计打圈**（P2d-17）——最直接的原因是
**神经看不到自己的运动状态**（P2d-23 审计：`brain.step` 无位姿/朝向/转动反馈，无 heading 保持）；
③ 最终目标（随机迷宫**有目的**导航）**必需**方向保持/探索状态，而当前架构完全没有。

**为何仍满足"真实 MaleCNS 主导导航"**：D 补的是**果蝇本来就有的**自运动/本体信息（efference copy / 前庭—本体感），
把它作为**输入**喂给同一连接组，让**网络自己**去做方向整合与转弯终止；**不引入** Dijkstra、人工路径追踪或老师。
规划器若仍存在，只能作为**独立披露、可消融的**对照，绝不接管转向。

**不推荐 A/B/C 的理由（基于本轮证据）**：A（重构感觉编码）——P2d-13d 已证移除 F 无改善；
B（验证动力学适用性）——重要但属"前提校验"，非对最终目标最缺的一环；
C（重研 motor map）——P2d-13b/14/22 表明改映射/保持/归一化均未改善，缺的不是映射本身。
