# P9-1a 报告：COBA-LIF 神经引擎**最小数值原型**（合成小网络验证）

**基线** `0f2512e`。**只测合成小网络**；**未**运行真实 MaleCNS 全脑、**未**接入车辆、**未**训练导航；
P1/正式权重/readout/BASE/tags 冻结。产出：`loop/coba_proto.py`、`loop/test_coba_proto.py`（**15/15**）。

## 1. 数值核心（单位一致）
单位约定（C[pF]、g[nS]、E[mV]、t[ms]、I[pA]；`C dV/dt`=pA，`tau=C/g`=ms）：
- 膜：`V <- V_inf + (V-V_inf)·exp(-dt/tau_eff)`，`tau_eff=C/g_tot`、`V_inf=(g_l E_l+g_exc E_exc+g_inh E_inh)/g_tot`
  （对定常电导为**精确解、无条件稳定**）；提供**内部子步长**对时变电导收敛。
- 电导：**精确指数衰减** `g *= exp(-dt_syn/tau_syn)`。
- **突触释放只来自 presynaptic spike 事件**（`g += g_unit·(W @ S_prev)`）——**非**复位前膜电位连续释放，
  **不**重包装已关闭的 P8 渐变释放。
- **不是 20 ms 显式欧拉**；已用**dt 收敛测试**与**子步等价测试**验证。

## 2. W 的**三层区分**（严禁混淆；`coba_proto.py` 顶部注明）
① 连接组**原始突触计数**；② `weights.npz` 的**逐突触后归一化相对权重**（L1≤1，**无单位**）；
③ **未知的绝对电导**。`W→g_syn` 需**额外定标**；原型用**声明的合成单位** `g_unit_nS`（测试取 10 nS，**非 nS 实测定标**）——
**禁止**把归一化 W 冒充 nS。

## 4. 合成测试（**15/15 ALL PASS**）
静息回归(V→E_l)、单个兴奋突触去极化、单个抑制突触超极化、**分流抑制**（E_inh=E_l 时削弱去极化）、
**多脉冲时间叠加**、**撤除后指数衰减**（与解析解一致）、**左右镜像对称**、**dt 收敛**（差分单调下降 2.44→0.32，≥5×）、
**子步等价**、无负电导/无 NaN、复位、可复现、**无 spike 则无电导**。
- 说明：收敛观测取**固定时刻 V**、**亚阈参数**（避免发放复位造成的跳变）；峰值为**子步级**记录（外层采样会漏瞬态）。

## 5. CPU 性能**实测**（非估计）
`N=166,700`、稀疏 `nnz≈1×10^6`：**≈7.2 ms/步** → 40 s 仿真(2000 步) ≈ **14.4 s**；状态内存 **5.33 MB**（float64，V/g_exc/g_inh/S_prev）。
（P9-0 的"2–4×"为**粗估**，此处为**实测**；真实全脑 nnz≈2.56×10^7，成本随之上升。）
