## 5. 逐神经元噪声配对

### 源码核验（安装的 `flybrain/brain.py`）

- SHA-256：`142ecfffd5d32e30655829e34b38b04024e49beae662bd078279e9610c789b0c`。
- `step()` 中**恰好一次** `self.rng.random((self.n, B))`；
- 在 `v *= decay; v += current + tonic` **之后**、在 `fired = xp.flatnonzero` **之前**；
- 该调用**不依赖 W、spikes 或 fired**；`step()` 中**没有其他 RNG 调用**；
- `reset(seed)` 使用 `self.rng = xp.random.default_rng(seed)`。

### 结论

在以下条件同时满足时，A/B 可**严格**共享同一逐神经元噪声序列：

1. 同一 seed；
2. 同一 `n=166,700`、`batch=1`；
3. 每条件**相同步数**（400）；
4. 每条件前 `reset(seed)`（RNG 重新创建）；
5. **CPU only**（CUDA 噪声流不同；不得混用）；
6. 无 stim/inject/eye_drive；无其他 RNG 调用；
7. 同一 NumPy 版本。

合成 RNG 测试：同 seed 的原始 `rng.random` 数组**逐位相等**；不同 seed 的原始数组不同。
Bernoulli 事件是阈值化视图，可能偶合；配对单位是**原始随机流**。

## 6. 统计预注册（已冻结）

### 主要终点

- **匹配 320 KC 在 [100,300) 的每步发放占比**；
- **每个 seed 单独统计**；
- 效应：**B − A** 的 **25 个 paired seed 差值**；
- 以 **seed 为独立重复单位**；**不得**把数千万 cell-step 当独立样本。

### 检验与区间

- **exact two-sided sign-flip**，25 个配对差值，枚举 **2^25 = 33,554,432** 个符号模式；
- 最小双侧 p = **2 / 2^25 = 5.960464477539063e-08**；
- **95% CI**：paired bootstrap **10,000** 次，seed **20261019**，2.5/97.5 percentile。

### 最低有意义效应

**冻结为绝对发放占比下降 0.10**（`mean(B−A) ≤ −0.10`）。
依据：0.10 是饱和表型的实质性损失，略大于 P11-1c 已观察到的 full-vs-subnet 差异 0.0882；
该阈值在 C1 运行前冻结，不能因结果修改。

### 判定

- **支持**：`mean(B−A) ≤ −0.10` **且** exact p < 0.05；报告 bootstrap CI。
- **不确定**：`mean(B−A) ≤ −0.10` 但 p ≥ 0.05，或任何必需 seed/条件缺失。
- **不支持**：`mean(B−A) > −0.10`，或 B 增加。
- 所有 25 seeds 全部保留；**不得删除/挑选 seed 114**；不替换缺失 seed；不重跑。
- 超时（>900 s）或 Job 峰值（>2048 MiB）→ **NO_GO**，不自动重试。

### 次要终点（描述性，不做多重校正因果声明）

- 完整 4,064 KC 的基线及 ≥0.85 / ≥0.95 比例；
- 95 matched / 97 full MBON 基线；
- 启动瞬态与最长连续发放；
- 低反馈子群体：**3 KCs（局部 2460、2650、3971；bodyIds 109321、117446、545375）**。

### 解释边界

- 若 B 下降 ≥0.10 且显著：最多支持 **KC→KC 边对当前模型饱和表型有因果贡献**；
  不自动证明特定反馈环路、生物机制或学习能力。
- 若 B 不下降：说明在所测条件下删除 KC→KC **不能有效解除饱和**；
  应继续调查非 KC 网络输入。
- **模型因果 ≠ 生物因果**；未保存的非 KC 活动仍可能参与。
