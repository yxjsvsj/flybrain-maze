## 2. LIF 机制审查 + **唯一修改**（requirement 3）
| 环节 | 实测 | 性质 |
|---|---|---|
| 感觉输入 | `eye_drive` 直加 `v[光感受器]×eye_gain(0.62)`；光感受器 R1-6/R7/R8 | 光感受器身份=**连接组数据**；注入方式=**模型假设** |
| 光感受器→视叶 | 平均入权 **−0.0235（净抑制）** | **连接组数据**（R1-6 组胺能=抑制，真实生物学） |
| 视叶→VPN | 平均入权 **+0.1299** | 连接组数据 |
| VPN→DN | 平均入权 **+0.0273（很弱）** | 连接组数据 |
| 膜电位/阈值 | `v←decay·v+gain·W@spikes+tonic+noise`，`v≥1` 发放 | 模型假设 |
| tonic/gain/noise | 0.14 / 3.0 / 1.2Hz,0.22 | **模型假设**（手工标定） |
| **权重归一化** | **无**：逐神经元入权和 均值 0.104、中位 0.117、max 1.0（阈值 1.0） | 连接组权重为原始计数 |

**唯一修改（冻结）**：**逐神经元入权 L1 归一化**（每行按 `1/Σ|w|` 缩放，行 L1=1）——synaptic normalization。
依据：连接组权重代表**相对突触效能**而非绝对计数；未归一化使级联输入（~0.1×gain）远离阈值。**gain/tonic/noise/阈值/eye_gain 全不变。**

## 5. 结论（requirement 6）
**NO-GO**。真实连接组**确含**解剖上的左右侧化视觉→下行基质（P3-1：LC4/LPLC4/LPLC2 近 100% 同侧），但在
**当前 LIF** 与**唯一一处有依据的归一化修改**下，**均未产生可靠的左右特异神经信号**。故：
- **不进入**任何虚拟神经控制/闭环阶段；不控车。
- 归因（更正）：非"通路断开"，而是**该动力学配置下无左右特异传递**（视觉驱动经 R1-6 净抑制进入视叶，
  且级联相对阈值过弱/无侧化）。
- 下一步若继续，需**另一类模型能力**（如显式视叶运动/looming 动力学、或按已知 LC4/LPLC2 looming 反应标定），
  **不属**本轮冻结范围，且**不**是读出参数微调。
