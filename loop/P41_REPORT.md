| 环节 | 实测 | 性质 |
|---|---|---|

| 光感受器→视叶 | 模型矩阵平均入权 **−0.0235（本模型中的净负值）** | **模型矩阵**：由真实连接组经**神经递质符号赋值 + 突触计数权重 + 逐神经元入权归一化**得到；**不得**把该负值直接读作"已实测的生理抑制" |

| VPN→DN | 模型矩阵平均入权 **+0.0273（很弱）** | 同上层（模型矩阵） |
| 膜电位/阈值 | `v←decay·v+gain·W@spikes+tonic+noise`，`v≥1` 发放 | 模型假设 |

| **权重归一化** | **flybrain 构建时已做**：`build.py:137` `w /= max(incoming_abs_sum, 1)` → 逐神经元入权 L1 总量 **≤1**；实测行和 均值 0.104、中位 0.117、max 1.0 | `build.py:135` 递质符号赋值 + 计数权重 + 入权归一化 = **模型矩阵**（非实测生理量） |

**唯一修改（冻结）**：在 flybrain **既有**归一化（L1≤1）之上，**再对非零行强制 L1=1**（每行按 `1/Σ|w|` 缩放）。
**这不是"首次归一化"**，而是把已被上限约束到 ≤1 的入权**统一到 1**。依据：模型矩阵权重代表**相对突触效能**。
**gain/tonic/noise/阈值/eye_gain 全不变。**

## 5. 结论（requirement 6）
**NO-GO**。真实连接组**确含**解剖上的左右侧化视觉→下行基质（P3-1：LC4/LPLC4/LPLC2 近 100% 同侧），但在
**当前 LIF** 与**唯一一处有依据的归一化修改**下，**均未产生可靠的左右特异神经信号**。故：
- **不进入**任何虚拟神经控制/闭环阶段；不控车。
- 归因（更正）：非"通路断开"，而是**该动力学配置下无左右特异传递**（在**模型矩阵**中，光感受器→视叶一路为**净负权**——
  这是**模型赋值**的结果、**不等同**于已实测的生理抑制；且级联相对阈值过弱/无侧化）。
  同时注意：**修改后的模型是否被执行尚不能由运行日志确认**（见 §2b），故本轮只能记 NO-GO，不宣称修改被验证。
- 下一步若继续，需**另一类模型能力**（如显式视叶运动/looming 动力学、或按已知 LC4/LPLC2 looming 反应标定），
  **不属**本轮冻结范围，且**不**是读出参数微调。
