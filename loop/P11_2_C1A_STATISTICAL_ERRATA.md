## 1. 主终点错误与更正

### 错误

历史 `p11_2_c1_experiment.py` 的 `_stats`、`_matched`、`analyze` 对 **完整 400 步**数组取均值；
预注册主窗口是 **[100,300)**。因此历史主终点
A=0.956807、B=0.194136、B−A=−0.762671 是 **full-400** 数值，不是预注册主终点。

### 从 25×2 原始 NPZ 重算

窗口固定 `[100,300)`，每 seed 先算 A/B 的 matched-320 均值，再取 25 个配对差值：

| 项目 | 值 |
|---|---|
| A matched-320 主窗口均值 | **1.000000000** |
| B matched-320 主窗口均值 | **0.201393125** |
| B−A 均值 | **−0.798606875** |
| SD（seed 单位） | **0.010585539** |
| median | **−0.798671875** |
| exact two-sided sign-flip | **p = 5.960464477539063e-08**（2/2^25） |
| 95% paired bootstrap CI | **[-0.802570, -0.794391]**（10,000 次，seed 20261019） |
| 预注册最低有意义效应 | **≥0.10 绝对下降**（即 mean ≤ −0.10） |
| 门槛 | **通过**（mean −0.7986，p < 0.05） |

与 GitHub 20 步分箱推算的 A≈1.000000、B≈0.201393、B−A≈−0.798607 相符。
正式值以原始 NPZ 为准。

**合成窗口守卫**：`test_window_guard_not_full_400` 构造 400 步数组（前 100=0，[100,300)=1，后 100=0），
断言主窗口均值=1.0、full-400 均值=0.5；可捕获“把 400 步误当 200 步主窗口”的回归。

## 3. 三个低反馈 KC：定量贡献，不是剩余活动的主要来源

其余 4,061 个 KC 贡献 **0.350706**。此前把三者描述为剩余活动主要来源的说法**没有独立定量依据**，现予撤回。

## 4. C1-A 与历史 P11-1c intact 对照

- **matched 320 主窗口**：C1-A **1.000000000**；P11-1c **1.000000000**（25/25）。

  matched 320 为 1.0；full-400 的 0.957269 是启动瞬态所致。

**噪声说明**：本比较**不**声称 P11-1c 与 C1-A 的逐神经元随机流已严格配对。
