`Training Authorization=False`。

## 1. 问题

在完整 MaleCNS 中，**KC→KC 递归输入是否是高 KC 饱和（匹配 320 KC 每步发放、完整 4,064 mean≈1）的必要条件？**

P11-2-0a 已证明：

- 无突触输入时，tonic 单独 / tonic+均值噪声不能每步发放；
- 最大噪声每步时，复位后最早第 4 步才能再发放，长期占比 ≤0.25；
- 历史 P11-1c 的 KC→KC 重建显示 99.9262% 的连续发放事件净输入 ≥0.86（容量）；
- 但**容量 ≠ 因果**；APL 等非 KC 输入未保存。

因此下一步只做**定向因果干预**，不先大范围调 gain/tonic/noise。

## 2. 干预对象（预先冻结）

- 对象：`W_KC_KC = W[kc_idx, :][:, kc_idx]`，4,064×4,064，**642,933 条边**（P11-1c 官方 W，只读复制）。
- 条件 B（zero）：把 `W_KC_KC` 全部置 0；**其余 W 完全不变**。
- 条件 A（intact）：原始 W。
- 条件 C（shuffled-degree）：保持 `W_KC_KC` 的**权重集合与边数**，把 pre/post 配对随机重排（固定随机种子）；用于区分“输入量”与“特定 KC→KC 结构”。
- **不改** gain、tonic、noise、阈值、reset、归一化、readout、其他 W；不新建连接；不训练；不更新 ΔW。

## 3. 设计（预先冻结）

- 网络：完整 MaleCNS（166,700 神经元），官方 `brain.npz` / `weights.npz`。
- seeds：**101–125（25 个）**，与 P11-1c 相同。
- 步数：**400**；分析窗口 **[100,300)**；无刺激（no-stim）。
- 条件：A intact、B zero KC→KC、C shuffled-degree；**3 × 25 × 400 = 30,000 步**。
- 资源：单进程；**2 GiB / 15 min** 硬上限；Job Object 保护；若超限/失败 → `NO-GO`，不重跑、不调参。
- 主指标：
  - 匹配 320 KC 的**基线发放比例/天花板**（逐 seed、逐 cell）；
  - 完整 4,064 KC 的基线/天花板；
  - 与 P11-1c intact 结果对照。
- 次指标：每步发放率、最长连续发放、每 cell 的零事件数、KC→KC 输入分布（仅 intact/zero 的诊断）。

## 4. 预注册判据

- **支持必要性**：B（zero）相对 A 显著降低匹配 320 KC 的基线/天花板，且 C（shuffled）不显著降低/降低幅度明显更小。
- **不支持必要性**：B 与 A 无实质差异。
- **非特异/输入量效应**：B 与 C 都降低，且差异小。
- 不按结果选参数；不因结果重启/加 seed；不把模型因果解释为生物因果。

## 5. 解释边界

- 这是**模型内**因果干预，不是真实果蝇生理因果。
- 即使支持必要性，也只说明该模型中 KC→KC 是高饱和的必要条件；不证明它是唯一机制，不证明学习/训练可行。
- 未保存的非 KC 活动（APL 等）仍可能参与；本实验不重建它们。
- **不训练、不更新真实 ΔW、不 Dijkstra、不迷宫、不 B/C、不实体车。**
- A1（单神经元 tonic+noise 稀疏概率）仍可作为独立可选项；不再是排除“tonic+noise 每步发放”的必要条件。
- **A2/A3/B 仍 NO-GO**；本提案是新的 KC→KC 定向干预，不是 A2/A3 的复活。
