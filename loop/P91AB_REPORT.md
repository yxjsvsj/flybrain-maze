# P9-1a-b 报告：COBA 原型的**脉冲时间精度**与性能基准修正

**基线** `ea97ac6`。保持电导型架构；**只跑合成数值测试**；不跑真实 MaleCNS 全脑、虚拟迷宫、实体车；
不改正式权重/车控；P1/readout/BASE/tags 冻结。产出：`loop/coba_proto.py`、`loop/test_coba_proto.py`（**21/21**）。

## 1. `step()` 修正：**逐子步**发放 + 及时复位 + 因果脉冲传递
外层 dt（可 20 ms）**不再**只看末值/末布尔：每个内部子步固定顺序
**① 电导精确指数衰减 → ② 突触传递（`g += g_unit·(W@S)`，`S`=**上一子步**发放计数）→ ③ 膜电位指数积分 →
④ 本子步阈值检查并**立即复位**；`S <- 本子步发放`**。多次子步发放均被记录（`spikes` 计数 + `spike_log`（神经元, 时刻））。

## 2. **确定性反例**：substeps=1 会漏记脉冲（可复现）
合成反例（经**脉冲事件**注入：`We[1,0]=5 → g=50 nS`，外层 dt=20 ms）：
- **substeps=1 → 只记 1 次**（且时刻=**20 ms 末**，错误）；
- **substeps=200 → ≥3 次**（首次于 **<2 ms**，正确）。
→ 证明"只靠最终膜电位/单个布尔"会**丢失事件**；已由逐子步检查修复。

## 3. 强化测试（**21/21 ALL PASS**）
静息回归、单兴奋、单抑制（用 **V_min** 判超极化）、**分流抑制**、时间叠加、撤除后指数衰减（解析一致）、
左右镜像、**亚阈 dt 收敛**（单调，≥5×）+ 子步等价、**超阈首次发放时刻随子步细化收敛**、
**复位正确性用 `V==V_reset`（而非"末值<阈"）**、**重复发放**、**负电导输入拒绝**（`g_unit<0` 与 `We` 负权均抛错）、
无负电导/无 NaN、可复现、无 spike 则无电导。

## 4. 施加顺序（固定）与收敛
衰减(①)→突触(②，事件)→膜积分(③)→阈值/复位(④)，每子步同序、子步间 1 子步突触延迟；
故**同一物理刺激在 dt/substeps 变化下收敛**（§3）。**不使用复位前 V 释放**。

## 5. CPU 性能**实测**（非估计；区分空闲 vs 有脉冲）
`N=166,700`、合成稀疏 `nnz≈1×10^6`、`dt=20 ms, substeps=1`：
- **空闲（无脉冲）≈5.6 ms/步**；**有脉冲（1% 发放）≈13.6 ms/步**（发放路径 ~2.4×）。
- 40 s 仿真=2000 步 → **空闲≈11 s / 有脉冲≈27 s**（此 nnz）。
- 状态内存 **5.33 MB**；**W(nnz=1e6) ≈12.67 MB**。
- **真实连接组 nnz≈2.56×10^7（≈25.6×）**：成本随 nnz **近线性增长** → **不得**把 1e6 边的**空闲**基准当作全脑速度；
  亦**不得**把 0.1 ms 子步成本直接套到 20 ms 运行模式。
