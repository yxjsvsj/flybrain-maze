| 轮次 | 现象 | 关键数 |
|---|---|---|
| **P5** 视觉 looming | 光感受器/T4T5 有反应（扩张为正、**收缩为负**），但 **LC4/LPLC2 无左右特异** | direction-ok 0/5 |

**定位**：瓶颈在**突触后整合与发放**，即**感觉层→VPN→下行 的逐级 `all-or-none` 阈值衰减**。
感觉层可被驱动（P5/P6），但模拟的**下行输入（~0.1×gain）远低于阈值 1.0**，且**弱而持续**的感觉信号
在每一级都需**跨阈**才能传递 → 到 DN 时已不足。这不是 P5 上游视觉问题，也非连接缺失（P7 有弱两跳）。

## 4. 唯一首选提案（可证伪）
**细胞类型特异「渐变（非脉冲）释放」**
- **改什么**：对指定细胞类型（视觉投射 `LPLC2/LC4` + 上游视叶/光感受器，可含 CX），把 **all-or-none 输出**
  替换为**渐变释放率** `r = clip(v, 0, 1)`（膜电位的模拟量）；下游输入由 `W@spikes` 改为 `W@r`。
- **为什么可能改善**：果蝇视觉与 CX 神经元**以渐变信号传递**；`all-or-none` 在**每一级**衰减模拟信号，
  而渐变释放让**弱而持续**的感觉信号**无阈值地传导**到下行靶——正对应 §2 的瓶颈。
- **参数依据**：**不引入新自由参数**——沿用现有 τ/gain/tonic/noise/阈值与**未改的连接权重**；
  唯一结构改动是 "all-or-none → 渐变 rate"（若需斜率，直接取现有噪声尺度 `noise_amp`，非搜索）。
- **可实施性**：在**新模块**中仅对指定 `cell_type` 覆盖输出（不改 flybrain 文件、不改官方权重）。
- **禁止**：不增大刺激、不调电机增益、不搜索最佳神经群、不注入航向/目标角。
- **会证伪该提案的现象**：
  1. 渐变释放下，`LC4/LPLC2 → DN` 的**左右特异**仍 < 预注册阈值（<4/5 seed 或 <3σ）；
  2. 渐变输出**未能**使 DN 靶对"刺激−对照"的增量 > 3σ（仍无下行响应）；
  3. 撤除后 DN 不回落（持续同向）或跨 seed 符号混乱。
- **能否支持神经自主停止转弯**：渐变释放下转向输出**连续跟随感觉驱动**（**非**计时器/固定转角）→ 驱动消失即输出衰减
  → 具备**停止转弯的必要机制**；是否**充分**须由 P8-1 验证（不以导航成功率反调）。
