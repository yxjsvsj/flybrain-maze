## 二、是否足够 → **部分足够**（并给出**预先固定**的重建方案，本轮不执行）
"PB" 网格缺失，但**EB/EBr\* 网格 + syn-points** 组合仍可给出**E-PG 的角向环坐标**（文献里 E-PG 在 EB 内按角向排布）。

**预先固定的空间重建方案**（可被独立证据验证；**不在本轮执行**）：
1. **取突触位置**：按 bodyId 取 46 EPG + 42 PEN 的 `syn-points`（pre/post 均取），得每细胞的突触 3-D 坐标集合。
2. **EB 归属**：以上一步的 **`EB`/`EBr*` 网格**做点-在-网格判定，算每细胞落在 EB 内的突触比例。
   *门槛先固定*：EB 内突触比例需 ≥ 某预设值，否则该细胞排除（并记录排除原因，不换阈值）。
3. **角向坐标**：对 EB 网格求**主轴平面**（PCA）→ 把 EB 内突触投影到该平面 → 取**极角**；每细胞的角向位置 = 其 EB 内突触极角的**圆形均值**。
4. **环序** = 按该角向位置排序；**稳定性**用子采样（与原 P2d-26a 同定义）报告。
5. **独立证据校验**（不参与定序，只用于验证）：
   a. 重建序上 **EPG→PEN 连接应呈"固定偏移"带状**（EPG_i 主要连到 PEN_{i±k}）——这是文献结构，未被用于定序；
   b. 与 **EBr\* 层**归属相容（同层细胞应聚在同一层 ROI）。
   仅当 (a)+(b) 同时成立，才判"空间坐标可被独立证据支持"。

**为何这不算用活动/角速度/期望朝向优化**：序完全由**解剖网格 + 突触位置**给出；(a)(b) 只是事后验证。

## 四、对 b9ae651 文档的两处修正（**不改真实数据结果**）
- **deg_gap 公式**：实际是 **`(λ3 − λ2) / λ2`（比值）**，判据阈值 `DEG_TOL=0.25`；此前写作"λ3−λ2"不准确。
  真实矩阵的该比值 = **0.369**（>0.25 → 低端**非**近简并对 → 未判环），结论不变。
- **稳定性指标含义**：`order_stability` = **子采样后相邻对在完整环序上仍相邻（环邻接 d∈{1,n−1}）的比例均值**——
  是**环邻接保持率**，不是相关系数、也不是显著性。真实矩阵该值 = **0.789**，结论不变。
