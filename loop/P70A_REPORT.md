- 旧版用 `W.getcol(j)` = 该神经元的**输出**列（`W[post, j]`），却当成了**输入** → 方向颠倒。
- 修正：输入 = **`W[post,pre]` 的行** `W[cell, :]`（`pre` = 源）。→ 旧报告里的
  *"DNa02 top inputs = vnc_intrinsic 2.551 …"* **其实是 DNa02 的输出目标**（DNa02→VNC，符合下降神经元常识）。

**开始转弯 / 左右选择（动态竞争）/ 结束转弯 / 回正**。"supported" 一律读作"存在解剖候选"，**非**"功能已实现"。
