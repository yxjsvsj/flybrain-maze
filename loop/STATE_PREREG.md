## 3. 分析（**只用**解剖角，不作为刺激的"正确答案"）
- 每窗：`PV = Σ r_i e^{iθ_i} / Σ r_i`（r=窗内该 EPG 发放数），相位 `arg(PV)`、集中度 `R=|PV|`。
- 相位**有效**当 `R ≥ R_VALID=0.20` **且** 窗内总发放 `≥ MIN_SPK=3`；否则相位 = **NaN**。
- 指标：局部性(窗口 R)、峰数、峰宽(FWHM, 20 角 bin)、相位有效率、撤除后**保持时长**、背景漂移。

## 4. 冻结阈值 / 判据
| 量 | 阈值 |
|---|---|
| `R_VALID`（相位有效） | 0.20 |
| `BUMP_R`（局部峰） | 0.30 |
| `MIN_SPK`/窗 | 3 |
| `SUSTAIN_MIN`（撤除后保持） | **1.0 s**（10 窗） |
| 参考时间常数 `TAU_REF` | 0.1 s（膜）→ 保持须 **≫ 10×τ** 才算"真实持续"，非滤波残尾 |
| 位置区分 `PHASE_SEP_MIN` | **90°**（两初始位置撤除后相位的圆差） |
| 空间打乱对照 | 相位在打乱角下应消失（R 显著下降） |

**结论门槛**
- **PASS**：confirm seeds 上，提示撤除后**可靠、空间局部化、随初始位置不同**的状态保持，且优于无提示/弥散对照。
- **PARTIAL**：有局部活动或短暂响应，但无可靠保持。
- **FAIL**：无可辨空间局部性；或仅为短期滤波残留 / 固定热点 / 背景漂移。
