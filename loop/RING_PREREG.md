## 1. EB 突触选择（冻结）
- **精确 token `EB`**：`roi` 值按 `;` 分词后含**恰好** `EB`。**不用** `EBr*`，**不用** bbox 包含代替。
- 主角坐标用 **pre+post 合并**（merged）；**pre-only** 与 **post-only** 各自另算并**并列报告**，
  用于一致性核对（**不**事后择一）。

## 2. 空间方法（冻结；仅由 EB 网格定轴）
1. 取 EB 网格顶点 `V`；**中心** `c = mean(V)`；对 `V-c` 做 PCA（SVD）→ `e1=PC1`、`e2=PC2`、`e3=法向`。
2. 突触点 `P` 的极角：`θ = atan2((P-c)·e2, (P-c)·e1)` ∈ (−π, π]。
3. 每细胞：`θ` 的**圆均** `μ = atan2(mean sinθ, mean cosθ)`、**圆集中度** `R = |mean e^{iθ}|`。
4. **不使用**任何神经活动或 EPG↔PEN 连接来定轴或定角。
5. **零点/正向是人为解剖参考**（`e1` 符号、0° 位置任意），**不是**小车/果蝇真实朝向。

## 3. 冻结阈值（人工分析标准）
| 项 | 阈值 | 含义 |
|---|---|---|
| `N_MIN` | **50** | 细胞在 EB 内（token EB）的最小突触数 |
| `RATIO_MIN` | **0.20** | EB 突触 / 该细胞全部突触 的最小比例 |
| `R_MIN` | **0.50** | 圆集中度最小（单一角扇区应高度集中） |
| `MODE_MAX` | **1** | 圆形直方图峰数上限（>1 判多峰→无效） |
| `UNC_MAX_DEG` | **30.0°** | bootstrap 角度不确定性(圆标准差)上限 |
| `BOOT_B` / `BOOT_SEED` | **500 / 0** | bootstrap 重采样次数/种子 |
| `SPLIT` | **50/50 随机，seed 0** | 分半稳定性 |
| 直方图 | **24 bins(15°)，3-bin 圆滑，峰≥25%最大值** | 多峰判据 |

**有效性** = `N_MIN ∧ RATIO_MIN ∧ R_MIN ∧ MODE_MAX ∧ UNC_MAX_DEG` 全满足；否则该细胞角度**标为无效**
（**不强行赋相位**）。**所有 88 个细胞**都报告，无效者附**原因**；排除只依上述**冻结规则**。

### 分组（冻结）
- `EPG`(46) / `PEN_a(PEN1)`(20) / `PEN_b(PEN2)`(22) **各自独立**；**EPGt 不自动并入 EPG**。

## 4. 独立验证判据（冻结；**不**用于调序）
1. **连接带状**：对每个 PEN 细胞，取其 EPG 输入的（角度 θ_i, 权重 w_i）→ 加权圆集中度
   `R_w = |Σ w_i e^{iθ_i}| / Σ w_i`（越大=越集中在某一角度=越呈"带状"）。
2. **空模型**：把 46 个 EPG 的**角度标签随机置换**（打乱 bodyId↔角度），重算 `R_w`，B=1000；
   `p = P(R_w^null ≥ R_w^obs)`。**分别**报告 PEN_a 与 PEN_b。
3. **分半稳定**：每细胞 EB 突触随机对半 → 两个角 → 圆差；报告**中位**与 <20° 比例。
4. **EBr\***：只作**层次一致性记录**，**不**当独立角序验证。
5. **不**依赖非水密网格的"点在网格"近似作精确标签；保留 P2d-26e 同框证据边界。

## 5. 最终判定（冻结为三档）
- **PASS**：可辨 EPG 覆盖 ≥ **0.80**（≥37/46），分半稳定**中位 ≤ 20°**，且独立连接证据
  `R_w` 相对空模型显著（`p<0.05`）的 PEN 细胞比例 ≥ **0.50**（PEN_a 与 PEN_b **各自**达标）。
- **INSUFFICIENT**：部分可定位，但覆盖率/集中度/验证证据不足。
- **FAIL**：数据或坐标方法有根本性问题，得不到可解释空间序列。

**即使 PASS**，只称「**具有解剖依据的候选环坐标**」；**不**宣称活动峰/神经罗盘/角速度积分/自主导航。
