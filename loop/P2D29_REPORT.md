## 1. 第一关：口径修正（仅离线重算，未重跑 P2d-28 六试次）
- "6.5–7.8 Hz" → **每秒换号率** `turn_sign_flips_per_s`；
- 首次侧别差归零**不**当作"障碍清除"（`lateral_diff_zero_t`，另报 `side_near_frac_L/R`）；
- **车辆响应不作独立故障**（删除 `V`）。归因 = **MN / MNS**。

## 2. 第二关：唯一候选 NS（预注册、参数固定、无搜索）
输入仅用固定 L50/R50 的 `D(t)`；因果整合 `τ_f=1.0 s`（=10× 实测背景相关时间 0.1 s），初值=b0；
`turn=clip(sign·gain·(D_f−b0), −1, 1)`，gain=8、sign=−1 **不变**。禁止项（ToF 原始距离/地图/目标/真角/老师/预定时长/手写方向）均遵守。

## 5. 失败机制（并入结论）
NS 只压"快"背景波动，**未去"慢/DC"偏置**：`LP(D−b0)` 长时均值仍非零 → 输出长期同号 → 净旋转 → 持续打圈。
ZERO 直线 0° 不能绕障（非等效成功）；FLIP 反向 → 碰撞 18–25 次。

## 6. 最终结论与分支关闭
- **FAIL**。依裁决**正式关闭当前 L50/R50 脑源电机读出改进路线**；不做小修小补、不搜第二候选、不调 τ_f/增益。
- 所需的下一步能力（而非继续小修）：网络需具备**与障碍锁定、低方差、零背景偏置的稳定神经表征**（= 已关闭的 EPG/PEN 状态路线所针对者）。
- 在**不改神经群 / 不加隐藏老师 / 不手写转向**约束下，**无**诚实可行路径 → **维持关闭**。
