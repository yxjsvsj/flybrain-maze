## 第二关（唯一候选 NS：预注册、参数固定）
- 输入**只用**固定 L50/R50 的 Trace(τ=0.2) 差 `D(t)`（当前与过去）；**禁止** ToF 原始距离/地图/目标/真实车身角/老师/预定转弯时长/手写方向。
- **因果时间整合**：`D_f ← D_f + (dt/τ_f)(D−D_f)`，**τ_f=1.0 s**（固定：=10× 实测背景相关时间 0.1 s）；初值 D_f(0)=b0（沿用既有 estimate_b0）。

## 失败机制（与 P2d-28 一致，且证明本候选不足）
- **NS 只抑制了"快"背景波动，未去除"慢/DC"偏置**：`LP(D−b0)` 的长时平均仍非零 → 输出长期同号 → 净角速度非零 → **持续打圈**（累计 905–2556°）。
- 离线"背景误转向↓63%"是在**长无遮挡**上测得（快分量）；**决定成败的 DC 偏置未被动摇**。
- ZERO 直线 0° 不能绕障（非等效成功）；FLIP 反向 → 碰撞 25 次。
