## 2. 工程老师（只在训练采集时使用）

```text
prox = 1 - dmin / max_range
turn_teacher = clip(3.0 * (prox_R - prox_L), -1, +1)   # 正 = 左
```

- `dmin_L` 只来自 FL/F，`dmin_R` 只来自 F/FR。
- 无障碍：`prox_R≈prox_L≈0` → 目标≈0。
- FL 近（左侧障碍）：`prox_L` 高 → 目标为负（右转）。
- FR 近（右侧障碍）：`prox_R` 高 → 目标为正（左转）。
- 双侧对称：目标≈0。
- 老师在推理时**不可用**，训练数据采集完成后从控制链移除。

## 5. 预注册门槛（不可事后改）

| ID | 门槛 | 固定判定 |
|---|---|---|
| G1 | 无障碍零偏置 | 验证 A 每个 seed `|mean| ≤ 0.05` |
| G2 | 单侧相反 | FL `mean ≤ -0.10`；FR `mean ≥ +0.10` |
| G3 | 双侧分离幅度 | `FR mean − FL mean ≥ 0.20` |
| G4 | 独立 seed 重复 | ≥ 80% 验证 seed 同时满足 FL<−0.10、FR>+0.10 |
| G5 | 撤除恢复 | 撤除后 1 s 内 `|mean| ≤ 0.05` |
| G6 | ZERO 消融 | neural turn=0，omega=0；方向性轮速差消失 |
| G7 | 特征打乱 | 原始方向准确率 ≥ 0.75；打乱特征后 ≤ 0.55（不重训） |

读数窗口固定：

- G1/G2/G3/G4/G7 用 `side_window = [2s, 6s)`；
- G5 用 `recovery_window = [6s, 7s)`（侧障碍撤除后第一秒）；
- 所有“mean”都是同一验证 seed 的窗口内 turn 均值；
- G7 方向准确率 = 验证 B_FL_only + C_FR_only 的 run 中，
  `sign(turn_mean)` 与期望方向一致的比例；打乱只置换验证 DN 特征行，不重训；
- G6 把 turn 强制为 0，检查 `omega` 精确为 0，左/右轮速差消失。

- 全部 G1–G7 通过才是 `PASS`。
- 任何一项失败必须报告全部 seed/repeat，不得只报成功 seed。
- 不允许改阈值、改距离、改老师、改增益、改滤波或换神经群。
- ZERO/FLIP 只作消融；不得作为正式演示方向。
- `CANDIDATE` 只有在数据通过后才可能成立；本轮没有数据，因此不是候选成功。
